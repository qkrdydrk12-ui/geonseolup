모바일 UI에서 관리자 권한 노출 및 레이아웃 깨짐 문제가 발생하고 있습니다.

현재 확인된 문제 2가지 수정해주세요.

---

1. 관리자 미로그인 상태인데 삭제 버튼 노출됨

---

현재 모바일 메인 공고 카드에서:
관리자가 로그인하지 않은 상태인데도

[삭제]

버튼이 사용자에게 노출되고 있습니다.

이건 심각한 권한 노출 문제입니다.

필수 수정사항:

1-1.
삭제 버튼은 반드시:
role=admin

로그인 상태에서만 표시해주세요.

예:
isAdmin === true
일 때만 렌더링.

1-2.
프론트 표시만 숨기지 말고:
backend/API 에서도 관리자 권한 검증해주세요.

1-3.
비로그인 또는 일반 사용자 상태에서는:

* 삭제 버튼 완전 숨김
* 버튼 영역 자체 제거

해주세요.

1-4.
SSR/hydration 문제로
초기 렌더 시 잠깐 노출되는 현상도 확인해주세요.

예:
로그인 체크 전 잠깐 삭제버튼 보였다가 사라지는 현상.

1-5.
모바일/PC 모두 동일하게 권한 체크 적용해주세요.

---

2. 모바일 화면 레이아웃 깨짐 수정

---

현재 모바일 상세페이지에서:

* 글씨 겹침
* 이미지/아이콘 겹침
* 줄바꿈 깨짐
* UI overflow

문제가 발생하고 있습니다.

예시:

* "21🍚55세"
* 현장명/모집인원 겹침
* 아이콘과 텍스트 충돌

등.

필수 수정사항:

2-1. 모바일 responsive layout 재정리
특히:
320px ~ 430px

모바일 width 기준 최적화해주세요.

2-2. flex/grid 정리
현재:
inline 요소들이 강제로 한줄 유지되면서
겹치는 것으로 보입니다.

모바일에서는:

* flex-wrap 적용
* 줄바꿈 허용
* column 배치 전환

해주세요.

2-3. 텍스트 overflow 처리
아래 적용해주세요.

* word-break: keep-all
* overflow-wrap: break-word
* text-overflow
* min-width:0

필요한 영역 적용.

2-4. 아이콘과 텍스트 간격 수정
현재:
아이콘이 텍스트 위로 겹치고 있습니다.

* gap
* align-items
* line-height

정리해주세요.

2-5. 모바일 폰트 크기 최적화
현재 일부 영역이:
font-size 과도하게 큼.

모바일에서는:

* 제목
* 상세정보
* badge

각각 적절히 축소해주세요.

2-6. 카드 내부 정보 재배치
현재:
현장명 / 모집인원 / 나이제한

한줄 배치 때문에 깨집니다.

모바일에서는:
세로(column) 배치로 변경해주세요.

예:
현장명
모집인원
나이제한

줄바꿈 배치.

2-7. badge/tag wrap 처리
NEW / 조공 / 경기

badge 들이 겹치지 않게:
wrap 허용해주세요.

2-8. 전화번호 영역 수정
전화번호가 길 경우:
overflow 되지 않게 처리해주세요.

2-9. 원문 textarea overflow 수정
원문 내용 영역도:
모바일 width 넘지 않게 처리해주세요.

2-10. 하단 버튼 고정 충돌 수정
"방문자 통계"
floating 버튼이
하단 CTA 버튼과 겹치고 있습니다.

safe-area 고려해서:
bottom spacing 조정해주세요.

2-11. 모바일 실기기 테스트
반드시:

* 삼성 인터넷
* 크롬 모바일
* 갤럭시 기준

실기기 테스트해주세요.

2-12. 관리자 모바일 UI 분리
관리자 버튼:

* 삭제
* 숨김
* 복제

는 모바일에서 compact UI 로 변경해주세요.

예:
... 메뉴 dropdown 처리 가능.

2-13. CSS 우선순위 충돌 점검
desktop css 가 모바일에 덮어쓰여
깨지는 부분 확인해주세요.

2-14. 전체 모바일 QA 진행
메인 리스트
상세페이지
관리자페이지
예약모달

전체 모바일 반응형 재점검해주세요.
