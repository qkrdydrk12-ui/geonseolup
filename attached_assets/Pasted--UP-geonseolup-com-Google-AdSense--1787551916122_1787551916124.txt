건설UP 사이트(geonseolup.com)를 Google AdSense 승인 심사에 유리하도록 아래 항목을 순서대로 점검하고 수정해줘.

중요:

- 현재 정상 작동 중인 기능과 디자인은 최대한 유지할 것.
- 기존 구인구직 데이터와 게시글은 삭제하지 말 것.
- 작업 전 현재 구조를 먼저 분석할 것.
- 이미 적용되어 있는 항목은 중복 구현하지 말 것.
- SEO에 악영향을 줄 수 있는 변경은 하지 말 것.
- 각 작업 완료 후 무엇을 수정했는지 알려줄 것.

1. 공고가 0개인 검색/필터 페이지 noindex 처리

지역 + 직종 등의 조합으로 생성되는 페이지 중 실제 구인공고가 0개인 페이지를 확인해줘.

예:
"검색 결과가 없습니다"
"총 0개"

이런 페이지에는 검색엔진이 색인하지 않도록 "noindex, follow"를 적용해줘.

단, 실제 공고가 1개 이상 존재하는 페이지는 기존처럼 index 가능하게 유지해야 한다.

사이트맵에도 공고가 없는 빈 필터 URL이 대량으로 포함되어 있다면 제외해줘.

canonical 설정도 함께 확인해서 중복 URL이 생성되지 않도록 해줘.

2. 건설UP 소개 페이지 추가

건설UP이 어떤 사이트인지 설명하는 별도의 소개 페이지를 만들어줘.

내용에는 다음 내용을 자연스럽게 포함해줘.

- 건설UP 서비스 소개
- 건설업 종사자를 위한 사이트라는 점
- 전국 건설현장 구인·구직 정보 제공
- 현장소식 제공
- 건설 실무 정보 및 건설꿀팁 제공
- 구인공고 정보 이용 시 주의사항
- 건설UP의 운영 목적

단순히 몇 줄짜리 페이지가 아니라 실제 사용자가 사이트의 목적과 운영방식을 이해할 수 있는 충분한 내용으로 만들어줘.

푸터에서도 "건설UP 소개" 페이지로 이동할 수 있도록 연결해줘.

3. 건설꿀팁 콘텐츠 구조 강화

현재 정보/건설꿀팁 게시판의 구조와 SEO 상태를 점검해줘.

각 글에 다음 요소가 제대로 적용되도록 해줘.

- 고유 title
- meta description
- H1 1개
- H2/H3 구조
- 작성일
- 수정일
- 관련 콘텐츠
- 내부링크
- 구인공고 연결
- canonical URL

P5 유도자 안전교육 같은 상세하고 실용적인 콘텐츠가 검색엔진에서 제대로 평가받을 수 있는 구조로 만들어줘.

기존 게시글 내용 자체는 임의로 삭제하거나 축약하지 마.

4. 현장소식 콘텐츠 SEO 강화

현장소식 게시판을 단순 뉴스 복사 사이트처럼 보이지 않도록 구조를 점검해줘.

각 현장소식 글에서 가능하면 다음과 같은 건설UP만의 정보를 제공할 수 있도록 콘텐츠 구조를 만들어줘.

- 핵심 내용 요약
- 공사/투자 규모
- 착공 및 완공 일정
- 예상되는 건설 인력 수요
- 관련 직종
- 근로자가 알아두면 좋은 내용
- 관련 건설UP 구인공고
- 관련 건설꿀팁

기존 현장소식 콘텐츠는 삭제하지 말 것.

5. 구인공고 상세페이지 자체 정보 강화

구인공고 상세페이지가 단순히 원본 공고를 보여주는 페이지에 그치지 않도록 개선해줘.

공고 데이터가 존재한다면 다음 정보를 보기 쉽게 정리해줘.

- 근무지역
- 모집직종
- 단가/급여
- 공수
- 숙소 여부
- 식사 여부
- 초보 가능 여부
- 근무기간
- 필요한 교육/이수증
- 연락방법
- 등록일
- 최종 확인일

원본 데이터에 없는 정보를 임의로 만들어내면 안 된다.

정보가 없으면 "정보 없음", "공고에서 확인되지 않음" 등으로 표시하거나 해당 항목을 숨겨줘.

6. 구인공고 출처 및 신고 시스템 강화

각 구인공고 상세페이지에서 사용자가 정보의 성격을 명확하게 알 수 있도록 해줘.

가능하다면 다음 요소를 제공해줘.

- 공고 출처
- 원문 보기
- 등록일
- 최종 확인일
- 신고 버튼
- 허위/마감 공고 신고 기능

그리고 적절한 위치에 다음 취지의 안내를 표시해줘.

"건설UP은 구인정보를 제공하며 실제 채용조건은 업체 또는 모집 담당자에게 반드시 다시 확인하시기 바랍니다."

기존 신고 기능이 있다면 새로 만들지 말고 기존 기능을 개선해줘.

7. 관리자 메뉴 사용자 화면에서 정리

현재 일반 사용자에게 관리자 메뉴 또는 관리자 링크가 노출되고 있는지 확인해줘.

일반 방문자가 사용할 필요가 없는 관리자 메뉴라면 일반 푸터/메뉴에서는 숨겨줘.

관리자 페이지 자체를 삭제하면 안 된다.

관리자는 기존 주소 또는 로그인 방식으로 계속 접근할 수 있어야 한다.

일반 사용자용 푸터는 가능하면 다음처럼 정리해줘.

- 건설UP 소개
- 이용약관
- 개인정보처리방침
- 문의하기

8. 사이트 신뢰성 페이지 점검

다음 페이지가 정상적으로 존재하고 접근 가능한지 확인해줘.

- 건설UP 소개
- 이용약관
- 개인정보처리방침
- 문의하기

각 페이지가 모바일/PC에서 정상적으로 열리는지 확인하고 깨진 링크가 있으면 수정해줘.

개인정보처리방침은 현재 사이트에서 실제로 수집하는 개인정보 및 사용 기능과 내용이 맞는지도 확인해줘.

실제 운영과 다른 내용을 임의로 추가하지 마.

9. 내부링크 구조 강화

건설꿀팁 → 현장소식 → 구인공고가 서로 자연스럽게 연결되도록 내부링크 구조를 개선해줘.

예:

P5 안전교육 글
→ P5 관련 구인공고
→ 관련 안전교육 글
→ 관련 직종 설명

SK하이닉스 현장소식
→ 용인/청주 관련 구인공고
→ 해당 현장에서 필요한 직종 정보
→ 관련 건설꿀팁

단순히 모든 페이지에 링크를 무작위로 넣지 말고 실제 관련성이 있는 콘텐츠만 연결해줘.

10. Google AdSense 및 전체 SEO 최종 점검

1~9번 작업이 끝난 후 사이트 전체를 다시 점검해줘.

특히 다음 항목을 확인해줘.

- ads.txt 정상 접근 여부
- AdSense publisher ID 정상 여부
- robots.txt
- sitemap.xml
- noindex 설정
- canonical
- 중복 페이지
- 빈 콘텐츠 페이지
- 404 페이지
- 깨진 내부링크
- 모바일 화면
- 페이지 title
- meta description
- H1 구조
- 개인정보처리방침
- 이용약관
- 문의하기
- 건설UP 소개
- 관리자 페이지 일반 노출 여부

중요:
현재 Google AdSense 심사가 진행 중이므로 애드센스 코드나 publisher ID를 임의로 삭제하거나 변경하지 마.

robots.txt에서 Googlebot 또는 Google AdSense 크롤러를 차단하지 마.

기존에 정상적으로 Google에 색인된 유용한 콘텐츠를 무작정 noindex 처리하지 마.

모든 작업이 끝나면 아래 형식으로 결과를 보고해줘.

1. 수정 완료 항목
2. 기존에 이미 정상 적용되어 있어 수정하지 않은 항목
3. 발견한 문제
4. 추가로 수정한 문제
5. 직접 확인이 필요한 항목
6. AdSense 승인 관점에서 현재 가장 위험한 부분
7. SEO 관점에서 추가 개선이 필요한 부분

한꺼번에 무리하게 코드를 변경하지 말고 기존 프로젝트 구조를 먼저 분석한 뒤 안전하게 작업해줘.
